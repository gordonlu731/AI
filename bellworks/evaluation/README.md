Use **Bellworks-AI-Input.zip** in a fresh model conversation. It contains only initial screenshots, scene/physics descriptions and an empty response template. This is a small retrospective, geometry-assisted case study with correlated interventions, not a general benchmark of physical understanding. Existing project reports are public, so a fresh context and no browsing/simulation are necessary protocol conditions. Local integrity receipts are not third-party timestamps.

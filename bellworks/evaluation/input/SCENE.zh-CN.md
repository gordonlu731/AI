# 初始场景说明

## 已知参考与观察时限

REF 是全部骨牌都在、没有额外红色挡板的原始配置。已知 REF 可以在同样的 30 模拟秒窗口内完成九阶段并撞钟。本材料不提供其用时，也不提供 X1～X4 的实测结果。所有图片都在释放钢球之前拍摄：模拟时间 0、九个阶段标志全部为 false。截图隐藏了界面文字和阶段面板，以免遮挡机构；对应开关设置由文件名和本说明给出。

每个待测场景独立完全重置，然后释放同一颗钢球，观察 30 模拟秒。物理步长为 1/120 秒，速度滑块不改变这个步长。30 秒是观察窗口，不是脚本触发时间。这个世界不会因为链条未推进而自动停止或宣布失败。

## 空间与传动关系

- +Y 向上，重力为 [0, −9.81, 0]。长度采用场景单位，时间为秒。`PHYSICS.json` 的四元数顺序为 [x,y,z,w]，尺寸为完整边长，不是半边长。
- 钢球半径 0.32，质量约 3.294；初始中心约 [−9.35, 12.25, −3.4]，初速度和角速度均为 0。Start 仅把球从固定刚体切换为动态刚体。
- 上层轨道在 z = −3.4 附近，从 x = −10 向 x = 8 下降。之后经有护栏的 180° 下降回旋弯道，转入 z = +3.4 附近的低层反向轨道。桥和翻斗位置有真实轨道缺口，下游还有一次落差。
- 机构依次分布为：斜坡、骨牌列、摆门、下降回旋轨道、四叶轮、带配重的跷板桥、带挡边与配重的翻斗、悬挂击槌、悬挂钟。球始终是同一个球，没有第二颗球被定时释放。
- 所有机械运动由重力、碰撞和被动旋转关节决定；没有电机、脚本推力或预设阶段动画。叶轮、摆门和击槌可以绕横向轴转动；桥、翻斗和钟另有关节限位。准确的轴、质量、碰撞体偏移和限位见参数文件。
- 黄色/绿色支柱及部分外观零件是装饰。参数文件所列的轨道表面、护栏、实体底板、末端挡块和活动机构才参与碰撞。图片中的视觉地面不是额外的物理地板。

## 骨牌与两个可控改动

骨牌从上游到下游编号 01～08。编号 i=0～7 的中心 x = −6.9 + 0.42*i + 0.076，中心高度在斜坡中心线上方约 0.382。01～07 的中心相对轨道中心向 +Z 偏移 0.43，尺寸为 [0.24,0.76,0.58]；08 的中心位于轨道中央，尺寸为 [0.24,0.76,1.80]。各骨牌初始姿态沿轨道倾斜，都是可自由运动的刚体，不是隐藏铰链。单块小骨牌质量约 0.037，08 约 0.115。

**Remove Domino**：仅删除 08 的可见模型、刚体和碰撞体；其余七块和其他机构不重新布置，也不修改它们的质量或速度。

**Add Obstacle**：额外加入固定红色方盒，中心 [−7.9,12.18,−3.4]，尺寸 [0.26,1.5,2.4]，姿态为单位四元数。斜坡地板宽 1.9，两侧护栏中心相距约 2.02。挡板没有电机、感应器或脚本事件。请根据这些实际尺寸与位置判断接触和运动后果。

X2 与 REF 的初始物理世界相同。“之前加过挡板”只是操作历史，本场景移除后执行完整重置，没有残留接触或动量。

## 如何判断阶段和碰撞

阶段列表的名称不是严格串行的脚本。九个标志按照真实位置、转动或碰撞条件独立锁存，曾触发就保持 true；其中骨牌阶段要求的是**剩余骨牌中至少六块**达到转动阈值，不要求必须存在全部八块。具体的四元数分量、角速度阈值和位置条件都列在 `PHYSICS.json` 的 `observer` 中。

六类待预测碰撞均指**钢球与该刚体**是否在 30 秒内发生过 Rapier 碰撞开始事件，依次为 barrier、gate、wheel、lever、bucket、hammer。其中 barrier 就是额外红色挡板。撞钟成功另由**击槌与钟体**的碰撞开始事件判定；单有开放端口、运动画面或钟的邻近位置不算成功。

## 参数文件的阅读方法

`objects` 给出所有活动对象的初始状态和每个碰撞体的局部偏移、旋转、尺寸/顶点及系数。`mass` 是从引擎读取的刚体质量。`joints` 给出固定轴承和连接约束。`track.centerline` 给出实际折线采样点，地板与护栏的尺寸、姿态和缺口由同节的构造规则确定。另有底板和末端挡块。

摩擦和恢复系数的合并规则枚举 0 表示平均值。参数里的球在释放前标为 fixed，这是启动机制，不代表释放后不受重力。所有数据均为未步进世界中的初始值，没有附带预测场景的未来坐标或运行日志。

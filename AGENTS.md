# Repository guide

This repository contains independent projects. Inspect the current branch and
working tree before editing; preserve unrelated files and existing user changes.

For A-share quantitative research, first read `a_share_quant/AGENTS.md`, then
`strategy_spec.md`, `research_log.md`, and the latest report in that directory.
Keep important research definitions, algorithm changes, and findings in Git.
The quant foundation branch is `quant-research-foundation`.

Bellworks work is maintained on separate existing branches. Do not overwrite,
merge, or force-push those branches as part of the quant project. Project-specific
quant data and testing rules apply within `a_share_quant/`.

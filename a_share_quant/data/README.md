# 数据契约、来源及许可

## 目录

`scripts/` 是可提交的获取与核验脚本。`raw/` 保存原始响应与请求审计，`processed/` 保存 CSV 和 manifest；后两者被 Git 忽略。`reports/` 只发布不含原始价格的研究摘要。**目前没有确认可再分发的真实行情样本**，因此没有向公开仓库提交行情。测试里的人工序列是明确标注的 synthetic fixture。

## 研究输入契约

CSV：`date,open,high,low,close,volume,adj_factor`。

- 日期为中国交易所当地交易日期，严格升序且唯一；开高低收为未复权人民币价格，volume 为真实成交股数。
- 所有 OHLC 和因子有限且 >0，volume ≥0，满足 `low ≤ min(open,close) ≤ max(open,close) ≤ high`。零量不表示可交易。
- `adj_factor` 是累计复权因子，生效日期不能晚于该行日期；研究时按第一行因子归一。不通过后复权收盘价/原始收盘价猜测全 OHLC 因子，不倒填未来首个因子。
- 日历另存 CSV：`date`，升序且唯一；证券停牌行不填造。观测指数日期只是日历代理，不能宣称官方交易所日历。

Manifest 必须包括 symbol、source、retrieved_at_utc、adjustment=`cumulative_factor`、volume_unit=`shares`、redistribution、数据/日历 SHA256、point_in_time_verified、calendar_verified。正式核验还须提供 verification_evidence；布尔标志本身不是证据。日期之外，未来还须增加供应商时间戳、数据修订版本和可用时点档案。

## 当前适配器

**新浪** `fetch_sina.py`：读取完整未复权日线压缩响应，通过固定版本 AKShare 的解码器解析；独立读取 `hfq.js` 因子，并使用有效日期不晚于当日的最近因子。额外与同源的近期 JSON 日线接口比较 OHLC 和股数成交量。全部网络请求有超时和有限重试，TLS 验证开启，网络响应不作为代码执行。可选解码器在隔离环境安装，核心算法与 CI 无此依赖。

**腾讯** `fetch_tencent.py`：逐年保存 raw/hfq 响应，检查日期覆盖，输出诊断，不输出可回测的因子 CSV。2026-10-23 初次尝试用两种收盘价的比例作为因子，被 OHLC/量核验拦截。该比例不满足统一乘法复权契约，可能涉及现金调整公式及历史修订；不能靠放宽阈值蒙混通过。保留诊断和差异日期，不把腾讯某种复权方式与新浪因子混用。

两者接口均属于供应商当前快照：即使因子带生效日期，也不能证明该版本在历史 t 时点已经可见。二次接口相同不等于第三方权威核验；腾讯/新浪也可能共享上游。不同源差异保留，不自动“择优”拼接。

## 下一阶段的正式数据要求

1. 获准研究和保存的数据来源及许可边界（公开仓库再分发与本地使用分开确认）。
2. 交易所交易日历、上市退市生命周期、逐日停复牌、历史 ST/板块/涨跌停价格与限售规则。
3. 公司行为原始记录、复权公式和每次修订的可用时间；校验除权日附近的原始价格、持股与现金变动。
4. 至少另一独立来源核验全部异常日期；保留数据错误隔离清单，而不是删掉亏损样本。
5. 如增加财务/事件，按首次公告时间和修订时间保存，不能只保留最新数据库行。

数据密钥只用 Cloud 的 secret binding；不写入源代码、shell 历史、日志或 Git。当前采集使用公开端点，没有配置付费数据密钥。

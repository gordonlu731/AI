# 首批六张真实盲标汇总口径

在计算本次六张汇总前登记。冻结全部结构参数、R0/R1 源码、原样本/顺序/截点与数据版本；不计算收益、不拟合模型、不解封独立测试。本协议只是人工结构对照的描述口径，不替换原预注册一对一评分。

## 输入与计数

累计 JSON 逐案例与上次上传核对：区分新增首次盲标、未变旧记录、揭示后修改。原件与全部操作历史归档，最终状态按唯一 case_id 统计，不把撤销框或重复导出重复计数。仅已完成标注的案例可揭示。首批六张完成不等于全部 12 组完成。

人工中枢、底部区域、无中枢、不确定、未填分别记录。底部可为局部止跌/中枢下沿承接，并非必须满足二次探底信号；B001 标于口头澄清之前，B002–B006 标于澄清之后，保留这一流程差异，不事后替用户统一底部子类。条件性的未来路径备注作为用户假设保存，不用后续行情验证。

## 同时保留三种范围

1. **末日全库存**：冻结算法截至图末仍保留/有效的所有区间，包括窗前旧区间与角色转换。数量差不是误识别数。
2. **末日有效且窗内新确认**：复用 B001 已报告的补充口径。对每个人工中枢保留全部价格 IoU 配对、上下沿差/人工宽度与宽度比。没有候选时，最大 IoU 留 unavailable，同时报告候选为零，不能静默记零或剔除。
3. **历史阶段补充对照**：读取同一冻结截点保存的全部区间，包括 expired/invalidated。候选必须在可见窗口内确认，确认 K 不晚于人工框结束，终止 K 不早于人工框开始；未终止以图末计。逐人工框保留所有符合该时段条件的配对。该范围用于诊断生命周期/历史框与当前有效支撑语义不一致，不能取代末日范围，也不当作更优模型。

历史阶段使用的是截点保存几何，不宣称几何在确认时或整段历史中都完全相同；不是交易信号回放。时间只作为候选相遇条件，不将人工整理框与算法支撑寿命强行计算同义的矩形 IoU。灰色终止区间图仅示意最近若干条，完整清单/配对不裁减。

## 汇总与缺失

- 每个人工框的最大价格 IoU 用于定位候选；无预设“正确”阈值，不凭它生成准确率。多个框分别报告，保留全部候选配对，不允许同一算法框匹配多个手工框的最大值被冒称一对一召回率。
- 每种范围报告候选数量、候选为零数量、无正价格交集数量、最大 IoU 的可计算分母、宽度比及上下沿差。连续值仅是描述，不给算法排名或新综合权重；无中枢案例不混入有中枢 IoU 均值。
- 底部不与中枢混配。人工重心未填则重心误差 unavailable，不用几何中点代填。正确/偏高/偏低/遗漏/误识别以用户揭示后明确判断为准，尚未收到则 pending。可自动列“结构分歧待核查”，不可冒称真人错误标签。
- 跨案例报告时明确当前样本只覆盖若干股票组、同股不同截点有关联，不把六张当六只独立股票。不计算显著性、收益或总体泛化效果；观察到的共同倾向仅列为后续待验证问题。
- B007–B012 仍未展示，股票映射与真实日期不进入公开汇总；价格图/原件/完整价格范围留在忽略目录，Git 仅发布白名单派生记录和哈希。
